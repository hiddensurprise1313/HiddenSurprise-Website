# Hidden Surprise - Bespoke Celebrations & Gifting Platform ✨

A modern, high-converting web platform for **Hidden Surprise** — a premier surprise event planning, bespoke gifting, and celebration experience brand.

![Hidden Surprise Banner](https://images.unsplash.com/photo-1513151233558-d860c5398176?auto=format&fit=crop&w=1200&q=80)

## 🌟 Key Features

1. **Interactive Surprise Builder Wizard**:
   - 4-step interactive customizer (Occasion $\rightarrow$ Experience Format $\rightarrow$ Add-Ons $\rightarrow$ Live Estimate).
   - Real-time pricing calculations, discount coupon application, and instant booking summary.

2. **Celebration Mystery Box (Unboxing Game)**:
   - Interactive 3D unboxing animation with confetti bursts.
   - Guaranteed celebratory rewards (e.g. 20% discount codes, free gourmet cakes, cold sparkler upgrades).

3. **Curated Signature Packages**:
   - Filterable catalog covering Midnight Serenades, Fairytale Candlelight Cabanas, Secret Trunk Reveals, Royal Proposals, and Luxury Keepsake Trunks.
   - Pricing comparison, inclusion checklists, and review ratings.

4. **Stealth Concierge & WhatsApp Booking**:
   - Frictionless booking modal that automatically constructs structured WhatsApp booking payloads with custom instructions and stealth protocols.

5. **Real Moments Gallery & Reviews**:
   - Filterable photo wall with lightbox view.
   - Verified client stories and star ratings.

6. **Luxury Celebration UI / UX**:
   - Midnight Indigo & Rose Gold aesthetic with glassmorphism, dynamic glowing ambient backdrops, responsive grid layouts, and micro-interactions.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)

- **Celebration Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
